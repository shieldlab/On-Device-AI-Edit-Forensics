ConsumerGenEdit Dataset

Real on-device generative edits from Apple, Samsung and Google devices, each paired with its original and three learned-compression variants.

Demo subset

Download

4,000 original–edited pairs in eight groups (Apple, Galaxy, Pixel and five cross-device chains), 500 per group, each with Q6, Q4 and Q2 compressed versions, plus metadata and per-operation manifests.

Download demo subset ConsumerGenEdit-demo.zip · about 6 GB · 31,000 files

Layout

ConsumerGenEdit-demo/
├── README.md
├── metadata.json                  one entry per pair: group, platform, device, category, files
├── remove.json  move.json  generate.json
│                                  manifests by edit operation, with paths to all variants
├── apple/  galaxy/  pixel/        single-device groups, 500 pairs each
└── crossdevice_<source>_<editor>/ five cross-device groups, 500 pairs each
    ├── original/                  <category>_<id>_original.jpg
    ├── edited/                    <category>_<id>_edited.jpg
    └── compressed/Q6 Q4 Q2/       same file names, original and edited
